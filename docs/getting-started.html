Início Rápido (Getting Started) 🚀

Aprenda a instalar o CDWA e conectar seu primeiro bot ao WhatsApp em menos de 2 minutos.

1. Instalação

npm install cdwa

Para projetos TypeScript, garanta que possui as definições de tipo:

npm install -D @types/node typescript

2. Código do Primeiro Bot

Crie um arquivo chamado bot.ts:

import makeWASocket, { useSecureAuthState } from 'cdwa'

async function startBot() {
  // 1. Armazenamento seguro de sessão protegido por senha mestra
  const auth = await useSecureAuthState('./auth_info', 'minha-senha-secreta-forte')

  // 2. Instancia o cliente com exibição de QR Code
  const sock = makeWASocket({
    auth,
    printQRInTerminal: true,
  })

  // 3. Monitora status de conexão
  sock.on('connection.update', (update) => {
    const { connection, qr } = update

    if (qr) {
      console.log('📌 Escaneie o QR Code no seu WhatsApp:', qr)
    }

    if (connection === 'open') {
      console.log('✅ Bot conectado com sucesso!')
    }
  })

  // 4. Conecta ao WebSocket do WhatsApp
  await sock.connect()
}

startBot().catch(console.error)

3. Executando o Projeto

npx tsx bot.ts

Abra seu WhatsApp no smartphone, acesse Aparelhos Conectados e aponte a câmera para o QR Code gerado!
