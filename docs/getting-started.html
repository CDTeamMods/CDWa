Início Rápido (Getting Started) 🚀

Aprenda a instalar o CDWA e conectar seu primeiro bot ao WhatsApp em menos de 2 minutos.

1. Instalação

npm install @cdteam/cdwa

Para projetos TypeScript, garanta que possui as definições de tipo:

npm install -D @types/node typescript

2. Usando em JavaScript Puro (.js)

Você pode usar o CDWA diretamente em projetos JavaScript sem precisar de compiladores ou TypeScript:

Com ES Modules (import - .js)

import makeWASocket, { useSecureAuthState } from '@cdteam/cdwa'

async function start() {
  const auth = await useSecureAuthState('./auth_info', 'senha-secreta')
  const sock = makeWASocket({ auth, printQRInTerminal: true })

  sock.on('connection.update', (update) => {
    if (update.qr) console.log('QR Code:', update.qr)
    if (update.connection === 'open') console.log('✅ Conectado via JS puro!')
  })

  await sock.connect()
}

start()

Com CommonJS (require - .cjs)

const { default: makeWASocket, useSecureAuthState } = require('@cdteam/cdwa')

async function start() {
  const auth = await useSecureAuthState('./auth_info', 'senha-secreta')
  const sock = makeWASocket({ auth, printQRInTerminal: true })

  sock.on('connection.update', (update) => {
    if (update.qr) console.log('QR Code:', update.qr)
    if (update.connection === 'open') console.log('✅ Conectado via CommonJS!')
  })

  await sock.connect()
}

start()

3. Executando com Node.js Puro

node bot.js

Abra seu WhatsApp no smartphone, acesse Aparelhos Conectados e aponte a câmera para o QR Code gerado!
