Autenticação & Conexão no WhatsApp 🔑

Aprenda como iniciar a sessão, emitir o QR Code visual no terminal, conectar seu dispositivo ao WhatsApp Web Multi-Device e proteger as chaves criptográficas com segurança at-rest.

Protocolo Multi-Device Nativo
O CDWA conecta diretamente aos servidores WebSocket do WhatsApp (Noise Handshake) sem depender de navegadores pesados ou emuladores (como Puppeteer ou Playwright).

1. Como Conectar no WhatsApp

Para conectar seu bot ou aplicação ao WhatsApp, o fluxo consiste em 4 passos simples:

  1. Carregar o estado de autenticação: Usando useSecureAuthState(diretório, senhaMestra).
  2. Instanciar o socket: Passando o objeto de autenticação para makeWASocket({ auth }).
  3. Ouvir o evento connection.update: Para capturar o QR Code e detectar quando a conexão for aberta.
  4. Iniciar a conexão: Chamando await sock.connect().

Código Completo de Conexão (TypeScript / ES Modules)

import makeWASocket, {
  useSecureAuthState,
  shouldReconnect,
  isLoggedOut,
  DisconnectError
} from '@cdteam/cdwa'
import qrcode from 'qrcode-terminal'

async function connectToWhatsApp() {
  // 1. Carrega ou cria credenciais em pasta protegida (opcionalmente com senha)
  const auth = await useSecureAuthState('./auth_info', 'minha-chave-mestra-secreta')

  // 2. Inicializa o cliente WhatsApp
  const sock = makeWASocket({
    auth,
    // printQRInTerminal: true // Opcional: renderização automática nativa
  })

  // 3. Monitora o ciclo de vida da conexão
  sock.on('connection.update', async (update) => {
    const { connection, lastDisconnect, qr } = update

    // Emissão do QR Code
    if (qr) {
      console.log('\n📱 Escaneie o QR Code abaixo no WhatsApp:')
      qrcode.generate(qr, { small: true })
    }

    // Conexão estabelecida com sucesso
    if (connection === 'open') {
      console.log('✅ Conexão estabelecida com sucesso no WhatsApp!')
    }

    // Tratamento de queda ou encerramento
    if (connection === 'close') {
      const error = lastDisconnect?.error

      if (shouldReconnect(error)) {
        console.log('🔄 Conexão interrompida. Reconectando...')
        await connectToWhatsApp()
      } else if (isLoggedOut(error)) {
        console.log('❌ Sessão desvinculada pelo celular. Remova ./auth_info e gere novo QR.')
      }
    }
  })

  // 4. Conecta aos servidores do WhatsApp
  await sock.connect()
}

2. Como Emitir o QR Code no Terminal

O WhatsApp Web envia uma string de pareamento no formato ref,noisePublicKey,identityPublicKey,advSecretKey. Você pode convertê-la em um QR Code gráfico no terminal das seguintes formas:

Método A: Usando a biblioteca qrcode-terminal (Recomendado)

Instale o pacote auxiliar no seu projeto:

npm install qrcode-terminal
npm install -D @types/qrcode-terminal

Em seguida, use a função qrcode.generate com a opção { small: true } para caber perfeitamente no console:

import qrcode from 'qrcode-terminal'

sock.on('connection.update', ({ qr }) => {
  if (qr) {
    console.log('📌 Aponte a câmera do seu smartphone:')
    qrcode.generate(qr, { small: true })
  }
})

Método B: Usando a flag nativa printQRInTerminal: true

O CDWA possui suporte embutido. Ao passar printQRInTerminal: true nas opções de inicialização, a biblioteca renderiza o QR Code automaticamente no terminal se qrcode-terminal estiver instalado: 

const sock = makeWASocket({
  auth,
  printQRInTerminal: true // Emite o QR Code diretamente no console
})
Como escanear no smartphone
  1. Abra o WhatsApp no seu celular (Android ou iPhone).
  2. Toque nos três pontos verticais (Android) ou em Configurações / Ajustes (iOS).
  3. Selecione Aparelhos Conectados.
  4. Toque em Conectar um Aparelho.
  5. Aponte a câmera para o QR Code desenhado no seu terminal.

3. Armazenamento Seguro de Sessão (useSecureAuthState)

Diferente de bibliotecas legadas que salvam tokens em texto plano desprotegido, o CDWA permite encriptar todo o armazenamento local at-rest com AES-256-GCM e derivação de chave HKDF (RFC 5869): 

import { useSecureAuthState } from '@cdteam/cdwa'

// 1. Armazenamento básico sem encriptação at-rest
const authSimples = await useSecureAuthState('./pasta_sessao')

// 2. Armazenamento reforçado com senha mestra
const senhaMestra = process.env.WA_SECRET || 'chave-secreta-forte-e-longa-32-chars'
const authSeguro = await useSecureAuthState('./pasta_sessao', senhaMestra)
Reaproveitamento de Conexão
Após escanear o QR Code uma vez, as chaves ficam salvas na pasta informada. Ao reiniciar sua aplicação, o CDWA se reconectará automaticamente sem precisar escanear o QR Code novamente!

4. Cache em Memória com makeCacheableSignalKeyStore ⚡

No protocolo do WhatsApp, cada mensagem enviada ou recebida (especialmente em grupos grandes com centenas de participantes) necessita consultar e atualizar chaves do Signal (session, sender-key, pre-key).

Sem uma camada de cache, cada operação força leituras e escritas repetitivas no disco (fs.readFile) ou no banco de dados. A função makeCacheableSignalKeyStore cria uma camada de cache em memória de alta performance que reduz drasticamente as operações de E/S (I/O) e elimina gargalos de latência: 

import makeWASocket, {
  useSecureAuthState,
  makeCacheableSignalKeyStore
} from '@cdteam/cdwa'

const auth = await useSecureAuthState('./auth_info')

const sock = makeWASocket({
  auth: {
    creds: auth.creds,
    // Reduz drasticamente E/S em disco/banco armazenando chaves quentes na RAM:
    keys: makeCacheableSignalKeyStore(auth.keys)
  }
})
Compatibilidade Total com o Baileys
A função funciona de forma idêntica ao Baileys. Você também pode passar um Map personalizado, instâncias de NodeCache ou configurar limites de memória (maxKeys) e tempo de vida (ttlMs): 
// Exemplo com configurações de capacidade máxima de memória (LRU) e TTL:
const cachedKeys = makeCacheableSignalKeyStore(auth.keys, {
  maxKeys: 20000, // Máximo de 20.000 chaves em memória (evita vazamento de RAM)
  ttlMs: 24 * 60 * 60 * 1000 // TTL de 24 horas (opcional)
})

5. Exemplo em JavaScript Puro (CommonJS)

Caso esteja trabalhando em projetos legados ou scripts com require():

const { default: makeWASocket, useSecureAuthState, shouldReconnect } = require('@cdteam/cdwa')
const qrcode = require('qrcode-terminal')

async function run() {
  const auth = await useSecureAuthState('./auth_info')
  const sock = makeWASocket({ auth })

  sock.on('connection.update', (update) => {
    const { connection, qr, lastDisconnect } = update

    if (qr) {
      qrcode.generate(qr, { small: true })
    }

    if (connection === 'open') {
      console.log('✅ Bot conectado via CommonJS!')
    }

    if (connection === 'close') {
      if (shouldReconnect(lastDisconnect?.error)) {
        console.log('Reconectando...')
        run()
      }
    }
  })

  await sock.connect()
}
