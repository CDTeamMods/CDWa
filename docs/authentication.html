Autenticação & Gerenciamento de Estado 🔑

Gerencie as chaves do Signal e credenciais de sessão do WhatsApp sem expor dados confidenciais.

1. useSecureAuthState

Proteja todos os arquivos de sessão gerados pelo WhatsApp com AES-256-GCM: 

import { useSecureAuthState } from 'cdwa'

// Senha mestra via variável de ambiente
const secret = process.env.SESSION_SECRET || 'senha-mestra-longa'

const auth = await useSecureAuthState('./auth_info', secret)

const sock = makeWASocket({ auth })
Dica de Produção
Nunca adicione a pasta ./auth_info ao Git. Adicione-a ao seu .gitignore para evitar o vazamento acidental de chaves.

2. Armazenamento Remoto (Redis, PostgreSQL, MongoDB)

Para hospedar seu bot em servidores que não possuem persistência de disco (ex: Heroku, Render, AWS Lambda, Kubernetes), você pode implementar sua própria interface SignalKeyStore e carregar as credenciais a partir de qualquer banco de dados.
