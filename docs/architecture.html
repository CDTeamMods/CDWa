Arquitetura & Segurança Criptográfica 🔒

Entenda como o CDWA implementa as camadas de transporte e proteção ponta a ponta do WhatsApp.

1. Camada de Transporte: Noise Protocol

O CDWA se conecta via WebSocket seguro e realiza imediatamente o handshake Noise_XX_25519_AESGCM_SHA256:

  • Prólogo Oficial: WA\x06\x02 prefixado no pacote de saudação.
  • Chaves Efêmeras: Geração de par de chaves Curve25519 para garantir que sessões passadas não possam ser descriptografadas (Perfect Forward Secrecy).
  • Cifras Simétricas: Divisão em writeCipher e readCipher com Nonce sequencial de 64-bit para evitar ataques de repetição.

2. Formato Binário WABinary

O WhatsApp compacta stanzas XML em bytes binários. O motor BinaryProtocol converte nós estruturados: 

// Estrutura de Stanza no CDWA
const node = BinaryProtocol.createNode('iq', {
  to: 's.whatsapp.net',
  type: 'set',
  xmlns: 'pair-device',
})

3. Blindagem de Credenciais (Criptografia At-Rest)

O Risco do Baileys Tradicional
No Baileys, salvar credenciais com useMultiFileAuthState gera arquivos JSON com chaves privadas em texto puro. Se seu servidor for violado, suas sessões são expostas.

O CDWA resolve isso na raiz: todas as credenciais gravadas no disco passam por derivação de chave via HKDF-SHA256 e são cifradas com AES-256-GCM usando sua senha mestra.
