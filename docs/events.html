Eventos & Ciclo de Vida 📡

O cliente CDWA emite eventos tipados para que sua aplicação reaja a mudanças de conexão e mensagens.

1. connection.update

Disparado sempre que o estado da conexão muda, um QR Code é emitido ou ocorre uma desconexão.

sock.on('connection.update', (update) => {
  const { connection, lastDisconnect, qr, isNewLogin } = update

  if (qr) {
    console.log('📌 Novo QR Code disponível:', qr)
  }

  if (connection === 'open') {
    console.log('🟢 Bot online e conectado com sucesso!')
  }

  if (connection === 'close') {
    console.log('🔴 Conexão finalizada:', lastDisconnect?.error?.message)
  }
})

Inspecionando Erros de Desconexão 🔍

O CDWA fornece a classe DisconnectError e funções auxiliares (shouldReconnect, isLoggedOut, getDisconnectStatusCode) para inspecionar com precisão o motivo de uma queda e decidir se deve reconectar: 

import makeWASocket, {
  DisconnectError,
  DisconnectReason,
  shouldReconnect,
  isLoggedOut,
  getDisconnectStatusCode
} from '@cdteam/cdwa'

sock.on('connection.update', async ({ connection, lastDisconnect }) => {
  if (connection === 'close') {
    const error = lastDisconnect?.error

    // 1. Verificação rápida com helper inteligente
    const canReconnect = shouldReconnect(error)
    console.log(`Conexão encerrada. Pode reconectar automaticamente?`, canReconnect)

    // 2. Inspeção detalhada através da classe DisconnectError
    if (error instanceof DisconnectError) {
      console.log('Código de status HTTP/WS:', error.statusCode)
      console.log('Descrição em português:', error.reason)
      console.log('Motivo bruto do socket:', error.rawReason)
      console.log('Foi logout do celular (401)?', error.isLoggedOut)
      console.log('Recomendado reconectar?', error.shouldReconnect)
    }

    // 3. Tomada de decisão para reconexão
    if (canReconnect) {
      console.log('Tentando reconectar aos servidores do WhatsApp...')
      await sock.connect()
    } else if (isLoggedOut(error)) {
      console.log('❌ O usuário desvinculou o aparelho pelo WhatsApp no celular. Novo QR Code necessário.')
    }
  }
})

Tabela de Códigos de Desconexão (DisconnectReason)

Status Constante Significado Reconectar?
401 DisconnectReason.loggedOut Sessão desvinculada ou encerrada pelo celular ❌ Não (Requer novo QR)
403 DisconnectReason.forbidden Acesso bloqueado ou conta restrita ❌ Não
408 DisconnectReason.timedOut / connectionLost Timeout ou perda de ping/pong de rede ✅ Sim
428 DisconnectReason.connectionClosed Socket encerrado normalmente pelo servidor ✅ Sim
440 DisconnectReason.connectionReplaced Conexão sobreposta por outra sessão aberta ❌ Não
515 DisconnectReason.restartRequired Reinício solicitado pelo WhatsApp para sincronizar ✅ Sim
