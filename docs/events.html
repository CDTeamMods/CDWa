Eventos & Ciclo de Vida 📡

O cliente CDWA emite eventos tipados para que sua aplicação reaja a mudanças de conexão e mensagens.

1. connection.update

sock.on('connection.update', (update) => {
  const { connection, lastDisconnect, qr, isNewLogin } = update

  if (qr) {
    console.log('📌 Novo QR Code:', qr)
  }

  if (connection === 'open') {
    console.log('🟢 Bot online e conectado!')
  }

  if (connection === 'close') {
    console.log('🔴 Conexão finalizada:', lastDisconnect?.error?.message)
  }
})

2. messages.upsert

sock.on('messages.upsert', (data) => {
  console.log('📩 Nova mensagem recebida:', data)
})

3. creds.update

sock.on('creds.update', () => {
  console.log('🔑 Credenciais salvas no armazenamento!')
})
