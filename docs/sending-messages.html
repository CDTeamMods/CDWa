Guia Completo de Envio de Mensagens 📩

O método sock.sendMessage(jid, content, options) permite enviar todos os formatos suportados pelo WhatsApp.

1. Mensagem de Texto

await sock.sendMessage(jid, { text: 'Olá mundo!' })

2. Mensagem de Imagem (Buffer ou URL)

await sock.sendMessage(jid, {
  image: { url: 'https://exemplo.com/foto.jpg' },
  caption: 'Legenda da foto!',
})

3. Mensagem de Vídeo / GIF

await sock.sendMessage(jid, {
  video: { url: 'https://exemplo.com/video.mp4' },
  caption: 'Confira este vídeo!',
  gifPlayback: false,
})

4. Áudio e Notas de Voz (PTT)

await sock.sendMessage(jid, {
  audio: { url: 'https://exemplo.com/audio.mp3' },
  ptt: true, // Envia como áudio gravado no microfone (azul)
})

5. Documentos

await sock.sendMessage(jid, {
  document: { url: 'https://exemplo.com/arquivo.pdf' },
  mimetype: 'application/pdf',
  fileName: 'documento.pdf',
})

6. Localização GPS

await sock.sendMessage(jid, {
  location: {
    degreesLatitude: -23.55052,
    degreesLongitude: -46.633308,
    name: 'Praça da Sé',
    address: 'São Paulo - SP',
  },
})

7. Reações com Emojis

await sock.sendMessage(jid, {
  react: {
    text: '🚀',
    key: { remoteJid: jid, id: 'ID_DA_MENSAGEM' },
  },
})
